A one-line joke about working beside an AI coding agent, written for the developers who review its diffs every day. The house judge — an AI model — compares jokes pairwise and ranks them by how big a laugh they get from the reviewer of the change.

`main.py` (Python 3.13 stdlib only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, so both runs produce identical bytes. Deterministic, no network.
